# 인터뷰 기록 A

| 항목 | 내용 |
|---|---|
| 구분 | **사람 인터뷰** (AI 아님) |
| 응답자 | A (팀원, 비전공 수강생, 이번 교육의 이론·팀 프로젝트·개인 프로젝트 경험자) |
| 날짜 | 2026-11-16 |
| 동의 | **받음**(팀원 김영식 확인, 2026-11-21 기록). 이름·연락처는 적지 않음. 신원이 드러나는 고유명사(프로젝트 이름)는 11-21에 일반 표현으로 바꿈(뜻은 같음) |
| 방식 | 응답자가 자유롭게 경험을 말함 → 빅보스(AI)가 정리 |
| 한계 | **응답자가 서비스를 만드는 팀원 본인(1명).** 자기 확인 편향 가능. 팀 밖 인터뷰로 확인 전까지 근거가 아니라 **힌트** |

## 1. 직접 들은 말 (요약, 해석 없음)
작업 중 이런 불편이 있었다고 함(바이브코딩 시간, 프로젝트 수행 중).
1. "이 작업을 더 효율적으로 할 수 있는 기능은 없을까?"
2. "이 작업에 걸리는 시간이 너무 오래 걸리는데, 원인이 뭐지?"
3. "이 작업이 끝날 때까지 아무것도 안 하고 기다리는 대신, 멀티작업으로 시간을 절약할 수 있는 기능은 없을까?"
4. "내 결과물의 보완점이나 개선할 부분을 모를 때, 다양한 관점에서 피드백을 받을 수는 없을까?"
5. "결과물을 보여 주는 형태(PDF, HTML 등)의 디자인을 더 예쁘고 눈에 잘 들어오고 메시지가 잘 전달되게 하고 싶었는데, 목표치보다 수준이 마음에 들지 않은 적이 많았다. 그럴 때마다 분명히 품질을 끌어올릴 기능이나 기술이 있을 텐데 하는 아쉬움이 남았다."

**지금 쓰는 방법(실제 행동):** Claude Code에 작업을 시킬 때 "이 작업에 도움이 되는 스킬이 있는지 GitHub 또는 웹검색으로 찾아봐"라고 **자주** 입력함.

## 2. 팀의 해석 (들은 말과 구분)
- 계기는 "새 기술 소식"이 아니라 **작업 중 막힘·불만**.
- 5가지는 두 묶음: **과정 개선**(1 효율, 2 원인 진단, 3 병렬) / **결과 개선**(4 피드백, 5 디자인 품질).
- 5번의 "분명히 있을 텐데"는 **기능이 있다고 믿지만 이름·위치를 모르는 상태**를 보여 줌.
- 입력은 기능 이름이 아니라 **불편한 상황 문장**일 가능성이 큼.
- 가장 큰 기존 대안은 **Claude 자신에게 찾아 달라고 시키기**.
- 2번(원인 진단)은 도구 찾기보다 분석에 가까워 서비스 범위 밖일 수 있음.

## 3. 아직 모르는 것
- 가장 최근 "스킬 찾아봐"를 시킨 구체 장면(작업, 걸린 시간, 실제 사용 여부)
- 찾은 것이 쓸모없거나 틀렸던 경험
- 얼마나 자주, 한 번에 얼마나 걸리는지
- 다른 수강생도 같은 불편을 겪는지(팀 밖 인터뷰 필요)

## 4. 장면 답변 (2026-11-16, 직접 들은 말 요약)
**장면 ① 이전 팀 프로젝트 발표자료:** 발표자료에 쓸 영상의 퀄리티가 기대 수준에 미치지 못했음.
**장면 ② 전 직장 업무 정리:** 내가 했던 업무를 한눈에 들어오게, 업무 흐름과 카테고리별 분류를 마인드맵 형태의 연관성 시각자료로 만들고 싶었으나, 어떤 기능이 존재하는지, 어떤 기능을 써야 하는지 몰라서 못 했음. 나중에 "그라파이" 스킬을 알게 되어 "그때 알았으면 좋았을걸" 하는 아쉬움이 남음. (스킬의 정확한 이름 확인 필요)

## 5. 팀 해석 (들은 말과 구분)
- 두 장면 모두 해결하지 못한 채 끝남(①수준 미달, ②포기).
- ②는 "존재를 몰라서 포기"의 가장 강한 사례. 필요는 그때, 해결책 발견은 나중("그때 알았으면").
- 포기한 필요를 저장해 두었다가 맞는 도구가 나오거나 발견될 때 알려 주는 구조의 근거 후보.
- 사건 정의 후보: ⓐ 새로 나온 도구가 내 필요에 맞음 / ⓑ 이미 있었지만 내가 처음 발견한 도구가 내 필요에 맞음.
- 초반엔 "찾아보라고 시키는" 습관이 없어 포기, 지금은 습관이 생김 → 가치는 초기·초심자에게 큼(숙련 시 감소 가능).
- 필요가 "결과물의 표현"(영상, 시각화, 디자인, 피드백)에 모임.

## 6. 아직 모르는 것 (추가)
- ②에서 그때 검색이나 Claude에게 물어봤는지, 시도 없이 포기했는지
- 그라파이 스킬의 정확한 이름과 알게 된 경로
- ①의 영상 도구와 부족했던 점, 해결 시도 여부
- 두 장면의 날짜와 걸린 시간
