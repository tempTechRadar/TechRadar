# 화면 구조

> 화면 ID(IA-1~IA-22) 목록: 사용자 화면과 관리자 화면, 모든 화면의 공통 상태. (출처: docs/ia.md 1·3·4·5절)

## 큰 틀
- 메뉴는 로그인 아래 "사용자 메뉴(본인 데이터만)"와 "관리자 메뉴(관리자만)" 둘로 나뉜다. (출처: docs/ia.md 1절)
- 관리자 메뉴는 화면·서버·DB 모두에서 막는다. (출처: docs/ia.md 1절, 불변 5)
- 로그인 뒤 첫 화면은 기술 지도(IA-10)다(회의 D8). (출처: docs/ia.md 1절·7절 D8)
- 화면 ID는 요구·PR·QA에서 `IA-n`으로 부른다. (출처: docs/ia.md 머리말)

| IA-9 | 기록 찾기 | 지난 판단과 이유를 기술·종류·결과·기간으로 찾기. 본인 기록만 | 출처: docs/ia.md 3절 IA-9 |
| IA-10 | 기술 지도 (첫 화면) | 위에 판단 대기·최근 변경 띠, 내 기술을 가운데에 두고 같은 역할 기술을 한 단계까지. PC 기준 | 출처: docs/ia.md 3절 IA-10 |

## 관리자 화면
- 일반 사용자가 주소나 API로 직접 요청해도 막는다(화면·서버·DB). (출처: docs/ia.md 4절 머리말)
- 관리자가 무언가를 고치면 담당자·시각·사유가 남는다. (출처: docs/ia.md 4절 머리말)
- 관리자도 남의 알림에는 판단을 대신하거나 건너뛸 수 없다. 본인 알림은 사용자 메뉴의 IA-7에서 판단한다. (출처: docs/ia.md 4절 머리말, docs/adr/0016-관리자도-본인-알림은-판단할-수-있다.md)

| ID | 화면 | 한 줄 설명 | 출처 |
|---|---|---|---|
| IA-12 | 회원별 등록 | 회원마다 등록한 프로젝트·저장소 주소, 읽어 낸 기술 수, 마지막으로 읽은 시각 | 출처: docs/ia.md 4절 IA-12 |
| IA-13 | 수집 자료 | 출처별로 모은 자료와 이전 값·현재 값, 출처·기간으로 거르기 | 출처: docs/ia.md 4절 IA-13 |
| IA-14 | 알림과 처리 현황 | 모든 회원의 알림과 판단 상태, 처리한 사람과 시각. 판단 버튼은 없음 | 출처: docs/ia.md 4절 IA-14 |
| IA-15 | 수집 실행과 오류 | 수집 실행 기록, 수집 오류와 연속 실패, "지금 한 번 실행" 버튼 | 출처: docs/ia.md 4절 IA-15 |
| IA-16 | 흐름 화면 | `flow/flow.json`의 상자와 화살표, 시작 노드 6개, 상자 색, 화살표 위 건수, 채점 결과 | 출처: docs/ia.md 4절 IA-16 |
| IA-17 | 분류 확인 | 확신이 낮은 기술의 갈래 고치기, 같은 역할 후보 확정(관리자 확인만), 규칙 목록 고치기 | 출처: docs/ia.md 4절 IA-17 |

## 모든 화면의 공통 상태
| 상태 | 보여 줄 것 | 출처 |
|---|---|---|
| 데이터 없음 | "아직 등록한 프로젝트가 없어요" 등 + 다음 할 일 버튼 | 출처: docs/ia.md 5절 |
| 조회 실패 | "불러오지 못했어요" + 다시 시도. 데이터 없음과 다른 모양 | 출처: docs/ia.md 5절 |
| 수집 오류 | 해당 기술·출처에 "수집 오류". "변화 없음"·"삭제됨"으로 단정하지 않음 | 출처: docs/ia.md 5절, 불변 2 |
| 권한 없음 | 다른 사람 데이터나 관리자 주소에 들어오면 막고 안내 | 출처: docs/ia.md 5절, 불변 5 |
| 판단 대기 | 첫 화면 지도 띠·알림·대시보드에서 눈에 띄게 | 출처: docs/ia.md 5절, 불변 1 |

## 화면 크기와 알림 방식
- 대시보드(IA-5)와 알림(IA-6, IA-7)만 휴대폰에서 깨지지 않게 맞추고, 나머지는 PC 기준이다. (출처: docs/ia.md 5절, IA-Q8)
- 알림은 앱 안에서만 보여 주고 메일·메신저로 보내지 않는다. (출처: docs/ia.md 5절, IA-Q7)
