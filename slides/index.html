1막 · 문제 · 좋아졌는지 잴 숫자 하나

같은 저장소를 손으로 vs 앱으로

① 손으로

파일을 열어 깐 것을 적고, 기술마다 취약점 · 최근 업데이트를 검색

아직 재지 않았다

재는 방법: 같은 저장소 하나를 스톱워치로

② 앱으로

저장소 등록 → 사용 중인 항목 목록 → 등급과 이유 확인

아직 재지 않았다

재는 방법: 같은 저장소를 앱에 등록해 등급 확인까지

사용자가 없다 — 앱 안의 숫자는 시연 계정 값뿐이다. 빈도 · 손해는 수치로 따지 않고 당사자 말로 대신한다.

출처: docs/adr/0011(비교 작업 · 찾은 위험 수) · 화면 말 "사용 중인 항목" docs/adr/0043 │ 시간 2칸은 사람이 재서 E 키로 써 넣는다(지어 쓰지 않음)

  • 값을 쟀으면 숫자를, 못 쟀으면 "아직 재지 않았습니다, 재는 방법은 이것"을 그대로.
  • 사용자가 없다는 한계를 먼저 말한다.
  • 25초. 넘치면 말로 넘기는 쪽.
