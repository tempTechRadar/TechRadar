# 0030. 지도는 한눈에 볼 만큼(500개 · NEW 15개)만 올리고, 시연용 움직임을 넣고, 키보드 목록은 뺀다

- 날짜: 2026-11-21
- 상태: **확정 (사용자 결정, 2026-11-21 인터뷰)**. 팀은 PR 리뷰에서 확인한다
- 관련: ADR 0027(로그인 뒤 지도는 전체로, "최대 1,200개 + 내 기술 전부"), ADR 0029(로그인 전 서버 읽기), design.md 13절 2 · 17절, PRD-NF3(첫 화면 3초), 작업 `I-P-12d-map-demo`

## 배경
사용자가 지도를 보고 다음을 요청했다(11-21).
- 지도는 화면을 꽉 채우고 스크롤 없이 지도만 끌어 다니게.
- 범례 설명 · 상태 줄 · "목록으로 보기(키보드 · 화면 읽기)"는 필요 없다(보면 안다).
- 새 항목이 너무 많다. 사용자가 받아들일 수 있는 양을 생각해 줄이자.
- 레이더가 닿으면 기술이 생동감 있게 펼쳐지고, 옅게 남아 닿을 때 약하게 반응하게.

지금은 모은 기술을 최대 1,200개(운영에서 1,000개쯤) 올리고, 이번 주 NEW가 63개였다. 점은 처음부터 다 보였다(11-20 결정, 첫 화면 3초 때문).

## 결정
1. **지도에 올리는 모은 기술은 최대 500개**(`CATALOG_LIMIT`). 고르는 순서는 8항(내 기술 · 확정 비교군은 이 수와 따로 늘 들어감). 나머지는 지도 찾기 칸으로 찾는다. 내 기술 · 비교군은 이 수와 따로 늘 들어간다. ADR 0027의 "1,200개"를 이것으로 바꾼다. 기본이 전체 지도라는 점은 그대로다.
2. **지도 위 NEW 표시는 그 주 인기 상위 15개만**(`capNew`). 인기는 별, 그다음 주간 다운로드로 본다. 내 기술 · 비교군의 NEW는 늘 남긴다. "새 기술" 화면은 제한 없이 전부 보여 준다(둘러보는 곳이라서).
3. **찾기는 지도 찾기 칸 하나로 한다.** 순서는 다음과 같다.
   - 지도에 올린 것에서 찾는다.
   - 없으면 모은 기술 전체(공개 목록, ADR 0029의 공개 칸만)에서 찾아 "지도에 올리기"를 보인다.
   - 거기에도 없으면 "'이름' 직접 추가"를 보인다. 로그인한 사람만 쓸 수 있고, 내 프로젝트 또는 "프로젝트 밖"에 넣는다.

   지도 화면에서는 메뉴 바의 "찾기 · 넣기"를 숨긴다. 로그인 전 찾기는 서버 키로 이름만 찾고, 20개까지, 0.4초 쉬었다가 보낸다. 같은 글자는 10분 동안 캐시한다.
4. **레이더 움직임**은 다음과 같이 한다.
   - 처음에 선(또는 파동)이 1.8초 동안 지나가며, 기술이 부모 묶음 자리에서 제자리로 날아간다(마지막 점까지 첫 장부터 2.2초). 부모보다 먼저 나오지 않는다. 지도가 500개라 처음부터 다 펼쳐 둔다(접어 두는 기준을 400 → 700개로 올림).
   - 그 뒤에는 옅은 선 · 파동이 계속 돌고, 닿는 점이 옅게 빛난다.
   - ~~"보기 → 움직임"에서 도는 선 / 퍼지는 파동 / 끄기를 고른다.~~ → (같은 날 고침, 11항) 지도 오른쪽 아래 ⚙(레이더 설정)에서 방식(선 · 파동 · 끄기)과 분위기(잔잔하게 · 기본 · 생생하게: 도는 속도 · 파동 간격 · 잔광 묶음)를 고른다. 기본은 잔잔하게, 파동은 얇고 옅게. 둘 다 이 브라우저에만 기억한다. 분위기를 바꿔도 선 · 파동은 제자리에서 이어 간다(시작 시계는 그대로라 위험 맥박 10초 · 펼침은 영향 없음).
   - 기기에서 "움직임 줄이기"를 켜 두면 저절로 끈다.
   - 계속 도는 동안은 1초에 20장만 그리고, 탭이 안 보이거나 90초 동안 손대지 않으면 멈춘다(만지면 다시).
   - 11-20의 "점은 처음부터 다 보이게"는 이 결정으로 바꾼다.
5. **"목록으로 보기(키보드 · 화면 읽기)"를 뺀다.** 상태 줄은 화면에서 빼고 화면 읽기에만 알린다(`role="status"`).

6. **(같은 날 추가) 움직임은 시안 `design-concept-3/docs/wireframes/map.html`처럼**(사용자: "방사형이 퍼지고 배율이 축소되면서 퍼지는 느낌", 선 뒤 여운이 "깔대기 같다", "첫 화면 3초에 집착하지 말고 자연스럽고 몰입되게").
   - 처음: 가운데를 크게 본 채 고리가 안쪽부터 차례로 퍼지고 → 화면이 1.8초에 걸쳐 물러나며 → 선이 2초에 한 바퀴 돌고, 지나간 자리에서 기술이 작게 떠올라 제 크기가 된다(사용자: 가운데서 튀어나오는 것보다 지나간 자리에서 떠오르는 게 낫다. 연출 중에는 이름표를 숨김) → 0.8초에 걸쳐 16초에 한 바퀴로 느려진다.
   - 누르거나 휠을 굴리면 처음 연출은 바로 끝난다.
   - 여운은 각진 부채꼴 대신, 선 뒤 70도 안의 고리만 잠깐 밝아지는 잔광으로 바꾼다. 파동은 얇은 고리 하나가 번지며 옅어진다.
   - 4번의 "첫 화면 3초 안"이라는 조건은 뺀다(사용자 결정). 시간 값은 `app/tech-map/motion.ts` 한 곳에 둔다.
7. **(같은 날 추가) 기본 보기는 종류가 둘 이상이면 "종류 먼저"(종류 → 하는 일), 하나뿐이면 "하는 일 먼저"로 자동으로 정한다**(`defaultFor`).
   - 부트캠프 교육생 · 나 같은 사용자에게 스킬 · MCP · 개념부터 보이게 하려는 것이다.
   - 하지만 운영 공개 목록이 MCP뿐이다(공개 MCP 15,701개 · 스킬 0개 · 개념 0개). 그래서 지금은 "하는 일 먼저"로 보인다.
   - Claude Code 스킬 · 개념 · 새 개발 도구 "입문 세트"는 공식 출처로 확인한 목록을 만든 뒤 따로 승인을 받아 카탈로그에 넣는다(개발보조1 세션에 넘김).
8. **(같은 날 추가) 지도에 올리는 500개를 고르는 순서**는 다음과 같다(`readCatalog`, ADR 0027의 "위험 · 주의 → 두꺼운 것 → 최근"을 바꿈).
   - ① 위험 → 주의(100개까지)
   - ② 입문 세트(80개까지, ADR 0031): 별이 없어 별 순에 밀리기 때문이다. 개발 도구(sdk)는 여기로만 들어간다.
   - ③ 이번 주 새 기술(60개까지, 대량 채우기분 제외): NEW 표시 15개를 고를 몫. 별만 보면 새 기술은 별이 없어 빠지기 때문이다.
   - ④ 개발 분야(프론트엔드 · 백엔드·데이터 · 검사·보안 · 배포·운영 · AI 작업 방식 · 기획·문서와 그 세부 갈래)와 스킬 · 플러그인 · 개념을, 두꺼운 것 → 별이 많은 순으로
   - ⑤ 그래도 자리가 남을 때만 나머지를 같은 순으로

9. **(같은 날 추가) 첫 고리가 종류면 부채꼴 너비를 거의 고르게(네제곱근)**, 처음 접기는 "제 칸에 6줄 안에 못 들어가는 묶음만"으로 바꾼다(사용자 "추천대로").
   - 입문 세트를 넣은 뒤 MCP가 455개라, 너비를 √로 나누면 입문 세트 부채꼴이 좁게 몰려 이름표가 겹쳤다.
   - 완전히 같게 나누니 이번엔 MCP 칸이 좁아 그 안 묶음 이름이 겹치고, 작은 MCP 묶음의 점이 바깥으로 길게 쌓였다.
   - 그래서 네제곱근으로 나눈다(MCP 약 40%, 나머지 약 15%씩). 좁은 칸에 깊게 쌓일 묶음만 접는다(이전: 700개 넘으면 전부 · 40개 넘으면).
   - 처음 접기 규칙(리뷰 반영):
     - 맨 안쪽 묶음 중 실제로 6줄 넘게 쌓이는 것만 접는다.
     - 내 기술 · 위험이 든 묶음은 접지 않는다.
     - 모두 넘치면 700개 아래는 하나도 안 접고, 넘으면 다 접는다.
     - "이 분류만 보기" 안에서는 접지 않는다.
     - 필터 · 되살린 보기마다 새로 정하고, 사람이 직접 펼치거나 접은 것만 그 위에 남긴다.
10. **(같은 날 추가) 로그인 전 공개 칸(`TECH_COLUMNS`, ADR 0029)에 `is_official`을 더한다.** 사이드 패널 머리에 "공식" 배지를 보이려고. 레지스트리가 검증한 공식 조직(ADR 0019)이나 Anthropic 공식 저장소의 입문 세트(ADR 0031)라는 공개 사실이라 개인정보 · 내부 판단이 아니다. 캐시 키에 `TECH_COLUMNS`가 들어 있어 옛 캐시는 쓰지 않는다.

11. **(같은 날 추가) 지도 다듬기**(사용자 요청 목록 → Claude 비판 · 추천 Q1~Q9 → "전부 추천대로 진행", 작업 `I-P-12d-map-polish`).
   - **보기 묶음 탭**(노션 보기처럼): 입문자 추천(MCP 뺀 종류) · 이번 주 새 기술 · 보안 위험 · 내 관심(로그인) · 내 기술과 비교군(내 기술이 있을 때). 지금 지도에서 비는 기본 묶음은 숨긴다. "지금 보기 저장"은 로그인했을 때만 이 브라우저에 5개까지(`lib/map/presets.ts`). 계정 저장은 동결 뒤.
   - **늘 보이는 빠른 칩**(필터를 창 밖으로): 들어온 때(오늘 · 이번 주 · 이번 달, 주소 `t=`) · 위험·주의 · 내 관심(`mk=1`) · 내 기술과 비교군 · 수집 오류. "NEW만(7일)" 체크는 "이번 주" 칩으로 바꾸고 옛 주소 `new=1`은 이번 주로 읽는다. 이번 달을 보이려고 지도의 새 기술 몫을 30일까지 · 100개로 늘린다(최근 것부터, 8항 ③을 바꿈, NEW 표시는 그대로 7일, `PICK_RULE` dev-first-5). 칩 수는 지도에 올린 것만 센다(30일 새 기술이 100개를 넘으면 이번 달은 일부만).
   - **크롤 버튼 대신 "새로 들어온 것 보기"**: 공개 화면에서 실제 수집(외부 호출 · 시간 · 비용)을 부르지 않고, 이미 모은 이번 주 기술이 화면 밖 제 방향에서 날아와 제자리에 꽂히는 다시 보기로 한다. 수집은 관리자 화면 · 정기 실행 몫 그대로.
   - **레이더 설정은 보기 창 밖**: 4항 셋째 줄처럼 오른쪽 아래 옅은 ⚙ 작은 창.
   - **사이드바는 지도 위로 덮기만**: 미끄러져 들어오고, 열려서 도구 줄이 줄바꿈돼도 지도 위아래 여백 · 배율은 그대로. 가린 점을 고르면 그 점만 꺼낸다.
   - **배율 단계**(네이버 지도처럼): 처음 보기 대비 배율 z로 멀리(0.75 아래) 큰 묶음과 수만 · 처음 보기 2단계 이름과 점 · 가까이(1.8~) 모든 기술 이름 · 아주 가까이(3.5~) 한국어 한 줄 · 인기 · 보안. 문턱 앞뒤에서 스며든다.
   - **눈이 즐거운 요소는 사람이 한 일에 답하는 것만**: 찾은 자리 물결, 펼칠 때 번짐, 큰 묶음에 올리면 부채꼴 밝힘, 처음 열 때 묶음 수가 차오름. 저절로 계속 움직이는 것은 더 늘리지 않는다(레이더 선 하나로 충분).
   - **이름(코드 글자만)**: 패키지 → 개발 도구, 종류 "모름" → 직접 넣은 것(쓰는 곳 "모름"과 헷갈림), 분류 전 → 아직 분류 안 됨, 그 밖 → 기타. DB에 든 갈래 이름(AI 작업 방식 → AI 에이전트, 사람 확인 → 사람 승인)은 팀 확인 뒤.

## 고민한 것
- **지도 1,200개를 그대로 두고 NEW만 줄이기:** 바꾸는 것은 적다. 하지만 점이 많으면 펼침 움직임이 무겁고, 한눈에 읽히지 않는다.
- **300개:** 더 가볍지만, 분야마다 몇 개 안 남아 "지형"으로 보이지 않는다.
- **키보드 목록을 숨겨 두고 Tab으로 닿을 때만 띄우기(Claude 추천):** 사용자가 "아예 빼, 지금은 시연 때 화려하게 보여 주는 쪽에 집중"이라고 정했다.

- **진짜 크롤 버튼(사용자 요청 원문):** 시연에서 극적이지만, 공개 화면에서 외부 수집을 부르면 남이 눌러도 외부 호출 · 비용이 생기고, 실패하면 "수집 오류"를 시연 중에 보여 주게 된다. 다시 보기가 같은 장면을 안전하게 준다.
- **기간을 일 · 주 · 월 "보기"(화면 전체 바꾸기)로:** 지도 하나에 칩으로 두는 쪽이 다른 필터와 겹쳐 쓰기 쉽다.

## 결과 · 대가
- **접근성(대가):** 키보드나 화면 읽기만으로는 지도의 점을 하나씩 고를 수 없다. 이것은 `rules/code.md`의 "접근성(대비 · 키보드 · 대체 텍스트)을 기본으로" 규칙과 다르다. 같은 기술은 다음 화면에서 키보드로 볼 수 있다: 지도 찾기 칸(키보드로 찾아 고르면 사이드바가 열림), "새 기술", "내 레이더", 기술 상세. 동결 뒤 다시 정한다(되살린다면 `git log`의 `app/tech-map/keyboard-list.tsx`).
- 움직임은 사실에 묶인 것이 아니라 꾸밈이다. 불변 6은 흐름 화면에만 걸리므로 지도에서는 허용한다. 대신 움직임 줄이기 설정을 따르고, 번쩍임은 1초에 3번을 넘지 않는다.
- 운영 카탈로그는 11-19 · 11-20에 처음 채워져 지금은 오늘 · 이번 주 · 이번 달 칩 수가 같다(70). 정기 수집이 쌓이면 갈린다.
- 사이드바가 열린 채 창 크기를 바꾸면 위아래 여백은 닫을 때 다시 잰다.
- 로그인 전 찾기가 늘면 DB 읽기도 는다. 같은 글자 10분 캐시 · 20개 제한으로 줄인다. 글자를 계속 바꿔 부르는 것은 막지 못한다(IP별 제한은 동결 뒤).
