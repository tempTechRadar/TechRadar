# 0013. 문제정의 통합안을 승인하고 IA로 넘어간다

- 날짜: 2026-11-18
- 상태: **채택** (2026-11-18 회의 D1, 김영식·차세일·황재웅)

ADR 0005는 "가설 판정 결과는 새 ADR로", 문제정의 통합안은 "승인하면 ADR로 남긴다"고 약속했다. 회의 D1에서 통합안(`docs/문제정의.md`)을 "고칠 곳만 적고 승인"으로 정했지만 ADR이 없었다(개발 전 점검 11-18이 짚음).

## 정한 것
- 통합안을 승인한다. 문제는 문제정의 1절의 한 문장("내가 무엇을 깔았는지, 그게 안전한지, 더 나은 것이 나왔는지를 한눈에 볼 수 없다")이고, 서비스 기준 문장은 "지키고, 고르고, 옮긴다"다.
- 그룹1 인터뷰의 발화자 확인은 승인을 막지 않는다. 한계로 문서에 이미 적혀 있다.
- 이후 결정(D2 알파, D4 숫자, D6 취향, D8 첫 화면, D11 공개 범위)은 각 ADR(0009·0011 등)과 문서에 반영했다.

## 결과
- IA → UJ → PRD → 데이터설계 → erd → spec → plan 순서로 진행했다(모두 11-18 회의 승인).
- 문제정의의 옛 결정은 11-18 개발 전 점검에서 지금 결정으로 고쳤다(문제정의 바뀐 기록).

## 고르지 않은 것
- 그룹1 발화자를 확인한 뒤 승인: 발표까지 남은 날이 적어 다음 문서로 넘어가는 것이 더 중요했다.
