# 0004. 팀 저장소는 평가 직전까지 공개로 두고, 제출 때 비공개로 전환한다

- 날짜: 2026-11-17
- 상태: 채택

안내서는 팀 저장소를 비공개로 유지하라고 하지만, 개발 기간에는 다른 플랫폼과 공유하기 불편해서 공개로 둔다. 평가(제출) 직전에 비공개로 바꾸고 강사를 collaborator로 초대한다.

## 결과
- 공개 기간에는 올리는 모든 것이 바로 공개된다. 사람 인터뷰는 익명 ID만 쓰고 이름·연락처·소속을 적지 않는다. 비밀값은 지금처럼 `.env`에만 둔다.
- `stage-check`는 제출 전 점검 전까지 공개 상태를 ➖(이 ADR)로 판정한다. 제출 단계에서는 비공개 전환과 초대 수락을 다시 확인한다.
