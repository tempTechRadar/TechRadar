# 0032. 서비스 컨셉은 "지도에서 고르고, 청사진으로 옮긴다"

- 날짜: 2026-11-21
- 상태: **확정 (사용자 결정, 2026-11-21)**. Maestro 세션이 정리본을 보이고 사용자가 골랐다
- 관련: `docs/design.md` 1절·10절 19번, ADR 0026·0028, 용어집 "내 기술 목록"(_Avoid_ 도구함·내 도구)·"목록 내보내기"(_Avoid_ 이사), `docs/agents.md` 2026-11-21 컨셉 키워드 조사 2줄

## 배경
`docs/design.md` 1절의 컨셉은 "기술 레이더"였다(2026-11-18 제안). 그 뒤 기술 지도(ADR 0026), 1차 목적 "한눈에 보고 스스로 판단"(ADR 0028), 블루프린트 화면(`/blueprint`, PR #202)이 생겼다. 그래서 레이더라는 말이 지도와 "내 레이더"(`/views`) 둘을 가리켰고(design.md 10절 19번), 목록을 들고 나가는 장면(설치 프롬프트·블루프린트)은 컨셉에 들어 있지 않았다.

조사(서브에이전트 2개, `docs/agents.md` 2026-11-21 두 줄):
- **안쪽:** 문서·화면 문구에서 "지도"는 약 290줄(화면 약 80줄), "레이더"는 78줄인데 design.md에 몰렸고 화면에는 2곳이다. "청사진"·"연장"은 0줄이다. 용어집은 "도구함·내 도구"와 "이사"를 피할 말로 정해 두었다.
- **인터뷰(당사자 말):** 노트북 반납 전에 세팅을 "**싹 정리해서 가지고 나가**"겠다(그룹1 P1), "막막해서 그냥 **제로부터** 시작할 생각"(그룹1 P3 추정) (`interviews/2026-11-17-그룹1-사람.md` 20·22줄).
- **바깥:** 개발자 도구의 은유(Thoughtworks 레이더, Backstage 템플릿, Homebrew, Nix, JetBrains Toolbox 등)를 보고, "Blueprint"는 같은 분야에 이름이 겹치는 것(Agent Blueprint, claude-code-blueprint 등)이 있음을 확인했다.

## 결정
1. 서비스 컨셉은 **"지도에서 고르고, 청사진으로 옮긴다."** 지도는 보고 고르는 곳, 청사진은 고른 것을 다른 컴퓨터로 들고 가는 판이다.
2. 이름 **TechRadar**와 기준 문장 **"지키고, 고르고, 옮긴다"**는 그대로 둔다.
3. **레이더는 지도 위 "실제 확인 표시(도는 선)"로 낮춘다.** 선이 지나가 밝아진 점은 최근에 실제로 확인한 기술이라는 뜻은 그대로다(불변 2). 화면 이름이나 큰 은유로는 쓰지 않는다.
4. 화면에서 쓰는 **"블루프린트"는 "청사진"으로** 바꾼다. 화면과 용어집은 FrontLead가 PR #202에서 고친다.
5. **"연장"은 화면 단어로 쓰지 않는다.**

## 고민한 것 (버린 안)
- **레이더 → 청사진 두 단계 대신 레이더를 주 은유로 유지:** 이름과 맞지만 화면에서 쓰는 말은 "지도"가 훨씬 많고(약 80줄 대 2곳), "내 레이더"와 이름이 겹친다(10절 19번).
- **공방 / 연장:** 도구를 다룬다는 뜻은 맞지만 "연장"은 한국어 어감이 어색하고, 용어집이 피하기로 한 "도구함·내 도구"와 같은 자리다.
- **관제:** 감시·통제 느낌이 강하다. 판단은 사람이 한다는 규칙(불변 1, ADR 0010)과 맞지 않는다.
- **별·우주:** 지도의 별 모양과 이어지지만 옮기는 장면(설치 프롬프트)과 연결이 약하다.
- **"Blueprint"를 영어 그대로:** 같은 분야에 이름이 겹치는 것이 있어 한국어 "청사진"으로 쓴다.

## 결과와 남은 일
- `docs/design.md` 1절을 새 컨셉으로 바꾸고 옛 내용은 바뀐 기록에 남긴다. 10절 19번("레이더 이름이 둘")은 이 ADR로 닫는다.
- README 한 줄 소개에 새 컨셉을 더한다.
- **확인하지 못한 것:** techradar.com 등 "TechRadar" 이름 겹침, Homebrew 공식 용어, "청사진"의 한국어 어감(사람에게 물어본 적 없음). 이름은 코드 동결(11-23 18:00) 전에 바꾸지 않는다.
- 숫자(약 290줄·80줄·78줄·2곳)는 서브에이전트가 11-21에 origin/main과 `feat/P-12d-alerts-history`에서 센 값이다. 팀이 다시 세지는 않았다.
