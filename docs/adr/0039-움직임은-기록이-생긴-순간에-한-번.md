# 0039. 움직임은 기록이 생긴 순간에 한 번

- 날짜: 2026-11-22
- 상태: **확정 (사용자 결정, 2026-11-22)**. 움직임 묶음 P-12g(A 지도 · 덮개 FrontLead, B 청사진 · 현황 · 뼈대 DevAssi1, C 판단 · 종 · 토스트 · 흐름 DevAssi2)으로 만들고, #204로 main에 들어갔다
- 관련: ADR 0030 4항 · 11항(이 ADR로 바뀜), ADR 0032(컨셉), 불변 3 · 4 · 6, `docs/design.md` 4절, 계획 사본 `.claude/plans-share/p12g-motion-plan.md`

## 배경
- 11-21에는 지도 연출이 끝난 뒤에도 선 · 파동이 "잔잔하게 계속 돌고"(ADR 0030 4항), ⚙ 레이더 설정에서 분위기(잔잔하게 · 기본 · 생생하게)를 고르게 했다.
- 11-22에 테마 탐색 Workflow(에이전트 54개)가 테마 · 움직임 시안집을 만들었다(`docs/agents.md`). 사용자는 **테마(색 · 글꼴 · 판 무늬)는 그대로 두고 움직임만** 가져오기로 했다.
- 그때 기준을 하나로 정했다. 움직임은 꾸밈이 아니라 **방금 무언가가 실제로 기록됐다는 대답**이어야 한다.

## 결정
1. **움직임은 저장 · 기록이 성공한 뒤에 한 번만 한다.** 실패하면 아무것도 바뀌지 않는다(불변 4). 같은 결과가 다시 와도 두 번 움직이지 않는다(불변 3).
2. **지도 선은 첫 연출 뒤 멈춘다.** 11-21의 계속 돌기(초당 20장, 90초)와 ⚙ 분위기 칸을 없앤다. ⚙에는 처음 연출 방식(선 · 파동 · 끄기)과 범례 한 줄만 남긴다.
3. **빛나는 점은 최근 실제 확인뿐이다.** 수집 오류가 없고 마지막 확인이 36시간 안인 점만 빛난다(`lib/map/motion.ts` `recentlyChecked`). 위험 점은 맥박 대신 멈춘 이중 고리로 둔다.
4. **시간은 `--dur` 하나로 만든다.** 새 시간은 `calc(var(--dur) * k)`로 만든다. 움직임 줄이기에서는 `--dur`가 0이 되어 모두 즉시 끝난다. JS 움직임은 `prefers-reduced-motion`을 따른다. 예외는 되돌리기 막대 하나(고정 6초)다.
5. 새 라이브러리 · 색 · 토큰을 들이지 않고, `flow/flow.json`은 바꾸지 않는다.

## 만든 것 (P-12g, main 확인)
| 묶음 | 효과(기록이 생긴 순간) |
|---|---|
| A 지도 · 덮개 | 도는 선은 첫 연출 뒤 멈춤 · 최근 확인 점만 빛남 · 위험은 멈춘 이중 고리 · NEW는 한 번만 울리고 착지 이름표 · 칩으로 거를 때 점이 가운데에서 튀어나오지 않음 · 판단 저장이 성공하면 점 아래 꼬리표 · 덮개가 옅어지며 그 아래에서 연출 시작 · 덮개 단추 글이 켜진 이유를 말함(`gateText`) |
| B 청사진 · 현황 · 뼈대 | 카메라가 움직임 줄이기를 따름(버그) · 확정하면 선이 한 번 그어짐 · 후보 칩이 "고르는 중…" 뒤 실선 · 끄는 동안 빈 자리 윤곽과 "가득 참" · 현황 판단 대기 "새로 옴"(`lib/dashboard/since-last-visit.ts`) · 로딩 뼈대는 두 번만 깜빡임 |
| C 판단 · 종 · 토스트 · 흐름 | 판단 실패 글이 매번 다시 읽힘 · 저장 성공 첫 화면에 판단 도장 · 종 배지 수가 실제로 바뀔 때 한 번 · 토스트 올라옴과 되돌리기 6초 막대 · 흐름 화면 실행을 바꿀 때 색 전환 · 시연 · 실행 단추 진행 표시 |

## 고민한 것
- **11-21처럼 계속 돌기(⚙ 분위기로 고르기):** 시연에서 살아 보이지만, 도는 선이 "지금 읽는 중"처럼 읽힌다. 실제 읽기는 하루 1번 정기 실행이라 사실과 다르다. 탭이 열려 있는 동안 계속 그리는 비용도 든다.
- **시안집의 테마까지 가져오기:** 제출 이틀 전에 색 · 글꼴을 바꾸면 모든 화면의 대비와 QA를 다시 해야 한다. 사용자가 움직임만 고르기로 했다.

## 결과와 남은 일
- **ADR 0030을 바꾸는 곳:** 4항의 "그 뒤에는 옅은 선 · 파동이 계속 돈다"와 분위기 고르기, 계속 도는 동안의 그리기 규칙이 이 ADR로 바뀐다. 처음 연출(퍼지는 고리 → 물러남 → 한 바퀴)과 11항의 "사람이 한 일에 답하는 움직임만"은 그대로다.
- ⚙ 분위기를 지워도 이 브라우저에 저장된 옛 설정 값은 남는다. 읽지 않으므로 해가 없다.
- 로그인 전 지도는 저장소를 "0개 읽음"인 날에는 거의 빛나지 않을 수 있다. 사실이므로 그대로 둔다.
- 확정 선 긋기는 React Flow 내부 클래스(`react-flow__edge-interaction`)에 기댄다. 버전이 12.12.1로 고정돼 있어 허용했다.
- 제출 뒤로 미룸: 지도 "마지막 확인" 글과 선 각도 고정, 청사진 표제란 도장.
