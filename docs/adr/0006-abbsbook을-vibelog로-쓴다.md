# 0006. 개인 여정 기록은 vibelog 대신 abbsbook 스케치북에 남긴다

- 날짜: 2026-11-17
- 상태: 채택 (강사 확인은 팀원이 전달한 말, 제출 형식은 확인 전)

안내서 8장은 개인 기록을 vibelog(vibelog.kr)에 매일 남기라고 한다. 우리 팀은 이미 `abbs-log` 스킬(PR #9)로 단계마다 abbsbook 스케치북에 날짜·제목·한 줄 메모·화면 이미지·막힌 일과 푼 방법·정한 일과 이유를 남기고 있다. 같은 내용을 두 곳에 쓰면 한쪽이 빠지므로 abbsbook 하나로 쓴다. 팀원이 강사에게 물어 "abbsbook 기록을 vibelog로 인정"한다는 답을 받았다(2026-11-17, 팀 스케치북 "기록" 막대에 팀원이 적음).

## 결과
- 안내서의 vibelog 요건(날짜, 제목, 한 줄 메모, 화면 하나, 막힌 일과 푼 방법, 정한 일과 이유, 인터뷰한 날 내용, 자동 기록에 내 판단)은 abbsbook 이벤트로 채운다. **"내 판단" 칸은 사람이 직접 쓴다.**
- 인터뷰 대상 신원·비밀값·개인 데이터 화면은 스케치북에도 올리지 않는다.
- 아직 확인할 것: 강사에게 공유하는 형식(공유 링크), 팀 스케치북과 개인 스케치북 중 무엇을 개인 과제 증거로 볼지.
- `stage-check`는 점검할 때 이 ADR을 읽으므로, vibelog 항목은 abbsbook 기록으로 확인한다(스케치북을 커넥터로 못 열면 ❔).
