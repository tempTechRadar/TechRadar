# 0008. 개발을 시작하기 전에 데이터와 수집의 뿌리를 정한다

- 날짜: 2026-11-17
- 상태: 제안 (데이터설계 인터뷰에서 팀원 1명이 정함, 2026-11-18 회의 D9에서 팀 확인)

데이터설계를 하다가, 나중에 바꾸면 테이블과 수집 흐름을 통째로 다시 짜야 하는 것들이 나왔다. 개발을 시작하기 전에 아래처럼 정한다.

## 정한 것

1. **기술 신분증(기술 키)은 생태계와 이름으로 정한다.** 예: `npm:<패키지>`, `pypi:<패키지>`, `github:<owner>/<repo>`, `mcp:<레지스트리 이름>`, `hf:<id>`, `skill:<owner>/<repo>/<이름>`. 이름이 비슷한지로 맞추지 않는다. 이전 개인 프로토타입은 이름·별칭·AI 맞추기를 써서 오탐이 많았다.
2. **"내 기술"은 AI 코딩 도구만 넣는다**: MCP 서버, 스킬, 플러그인, LLM·에이전트 SDK. 일반 의존성까지 넣으면 GitHub Dependabot과 같은 서비스가 되는데, 그건 문제정의 10절에서 접은 후보다.
3. **보안 등급 근거는 OSV만으로 하지 않는다.** OSV는 npm·PyPI 패키지만 알기 때문에, 스킬과 GitHub에만 있는 MCP는 등급이 대부분 "찾지 못함"이 된다. 그래서 **위험 패턴 검사**(스킬 스크립트의 원격 실행·비밀값 읽기 등)와 **저장소 정보**(최근 활동·라이선스)를 함께 쓴다. 규칙은 `docs/spec.md`에서 정한다.
4. **GitHub API는 서버용 토큰 하나로 부른다.** 로그인 없이 부르면 시간당 60회라, 저장소 파일 5개와 기술마다의 저장소 정보를 읽으면 금방 넘는다. 토큰은 사람이 `.env`에 직접 넣는다.
5. **수집·분석·화면을 모두 TypeScript 한 언어로 만든다.** 이전 프로토타입(파이썬)은 로직만 옮겨 적는다. 수집기만 파이썬으로 따로 두면 배포와 실행 기록이 두 곳으로 갈라진다.
6. **이전 프로토타입의 데이터는 가져오지 않는다.** 2026-11-17에 조회해 보니 기술 292개의 대부분이 일반 IT 제품이었고, 설명 1,731건이 모두 미확인이었으며, 같은 역할 관계는 3개뿐이었다.
7. **만드는 순서를 고정한다.**
   - 1순위: 핵심 길(등록 → 내 기술 목록 → 등급 → 보안 경고 → 판단 → 기록)
   - 2순위: 알파(노션으로 보내기)
   - 3순위: 추천(가입 취향 조사)·Hugging Face·Hacker News·Firecrawl
8. **카탈로그는 관문 셋(분야 → 관련 → 근거)을 거쳐 "얇게 / 두껍게"로 넣는다.** 두꺼운 기술(누군가의 내 기술, 그와 같은 역할, 공식, 갈래 안 인기 상위 20개)만 등급 검사·매일 추적한다. 인기는 별 하나가 아니라 사용량·성장·화제·별의 갈래 안 순위로 정한다. 별 100 이상만 해도 약 7,000개라(2026-11-17 GitHub 검색 실측) 다 모으면 한도와 비용이 바닥난다. 자세한 기준은 `docs/데이터설계.md` 8절.

## 결과
- `docs/데이터설계.md`의 기술 키(7절)와 권한 표(4절)가 이 결정을 따른다.
- 출처는 OSV, 공식 MCP 레지스트리, GitHub 저장소 정보, npm·PyPI 다운로드 수, Hugging Face, Hacker News다(+ Firecrawl 1곳, 3순위). Appwrite는 쓰지 않는다. 안내서는 Supabase와 Appwrite 중 하나를 쓰라고 하고, 둘 다 쓰면 권한 검사가 두 곳으로 갈라진다.
- 메인 여정의 "깐 MCP가 위험으로 바뀜" 장면은 npm·PyPI 패키지인 MCP에서는 OSV로, 스킬에서는 위험 패턴 검사로 만든다.
- **확인하지 못한 것:** Vercel 정기 실행 횟수와 함수 실행 시간 한도. 수집을 짧은 실행으로 나눠 대응한다.

## 고르지 않은 것
- 모든 의존성 읽기: 범위가 커지고, Dependabot과 겹친다.
- 이전 데이터를 걸러서 가져오기: AI 코딩 도구에 맞는 것이 적고 모두 미확인이라, 거르는 비용이 얻는 것보다 크다.
- GitHub 로그인으로 사용자 토큰 쓰기: 비공개 저장소까지 열리는 장점이 있지만, 노션 로그인(ADR 0007)과 겹쳐 로그인 방법이 셋이 된다. 다음 버전에서 다시 본다.
