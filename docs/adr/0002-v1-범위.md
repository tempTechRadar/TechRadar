# 0002. v1 범위: AI 코딩 도구 생태계, 수강생 대표 사용자, 공개 저장소만

- 날짜: 2026-11-16
- 상태: 채택 (인터뷰 결과로 다시 볼 수 있음)

대상은 "AI 코딩 도구로 개발하는 누구나"로 넓게 두되, 판단 기준(관련 있음·안전함)이 흐려지지 않게 v1 대표 사용자를 바이브코딩 수강생 한 명으로 정했다. 지켜볼 분야는 그 사람들이 공통으로 쓰는 AI 코딩 도구 생태계(LLM, Claude Code 확장, 하네스 패턴, 개발 도구)로만 좁혔다. IT 전체 지도는 안내서가 경고한 "모든 뉴스 요약"처럼 알림 기준이 사라져서 접었다. 내 프로젝트 등록은 공개 GitHub 저장소 주소만 받는다. 비공개 저장소는 GitHub 로그인 연동이 필요해 다음 버전으로 미뤘다.
