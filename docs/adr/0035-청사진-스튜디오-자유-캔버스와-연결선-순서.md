# 0035. 청사진 스튜디오: 자유 캔버스, 순서는 연결선으로

- 날짜: 2026-11-21
- 상태: **확정 (사용자 승인, 2026-11-21 밤)**. Maestro 세션이 사용자와 인터뷰해 정한 계획(`I-P-12e-blueprint-studio`)이다. 구현 결과에 따라 아래 "결과와 남은 일"을 채운다
- 관련: ADR 0032(컨셉), ADR 0034(판단 = 청사진으로 가는 관문), ADR 0036(공개 범위 확장), 불변 1·2·5, `docs/design.md` 14절, 조각 P-12e

## 배경
컨셉 "지도에서 고르고, 청사진으로 옮긴다"(ADR 0032)에서 청사진은 핵심 화면이다. 그런데 11-21의 청사진(`/blueprint`)은 열·행 격자라서 몇 가지 한계가 있었다.
- 단계를 자유롭게 둘 수 없다.
- 화살표가 기술 카드보다 더 눈에 띈다.
- 서랍이 왼쪽에 붙어 있다.
- 템플릿 공유와 AI 점검이 없고, 단계 설계와 기술 배치가 나뉘어 있지 않다.

사용자는 피그마 · X-MIND · 유니티 · 언리얼처럼 바꾸고, 게임처럼 **① 단계 구축 → ② 스킬 붙이기 → ③ 결과물** 순서로 진행하기를 원했다(11-21 밤).

## 결정 (인터뷰로 정한 표 그대로)
| 항목 | 결정 |
|---|---|
| 순서 | **연결선으로 정한다.** 연결을 따라 순서를 매기고(위상 정렬) 깊이가 같으면 동시. 위치는 자유 |
| 캔버스 | **@xyflow/react 12.12.1** 고정(MIT, 11-02 배포). 13.x는 나온 지 2주가 안 돼 제외. **새 의존성, 사용자 승인 받음** |
| 템플릿 | **틀**(단계와 연결만)과 **조합**(단계와 기술) 두 가지. 공개 갤러리와 별명, 기본은 비공개(ADR 0036). "이 조합 써봤어요" 사용기 |
| AI 점검 | 확정본에서 **"점검 받기"를 누를 때만** 한 번. 결과는 **제안만** 하고 청사진은 바꾸지 않는다(불변 1). 하루 한도 |
| 휴대폰 · 스크린 리더 | 캔버스는 **보기만**, 편집은 **목록 모드**에서 |
| 오른쪽 | **속성 패널**(고른 단계 · 기술의 등급 · 내 태그 · 사용기 · 대체 기술) |
| 아래 | **하단 패널**(유니티식): 기술 · 내 이력 · 템플릿 · AI 점검 |
| 갤러리 | 하단 패널의 템플릿 탭 + 따로 둘러보는 화면 `/blueprint/gallery`. 메뉴는 지도 · 청사진 그대로(ADR 0034) |
| 단축키 | **거의 없이.** 단추가 중심이고, 키는 Esc · Delete · 스페이스 손 모드만 |
| 교체 | **바로 교체.** 안전망은 컷 라인과 옛 DB 함수를 남겨 두는 것 |

- **관문(ADR 0034)을 DB에서도 막는다:** 청사진에 넣을 수 있는 기술은 내 기술 · 적용 후보 · 내 이력뿐이다. ADR 0034가 적은 한계("화면에서만 막는다")를 마이그레이션 M1의 검사로 푼다. 위험 등급은 그대로 막는다(ADR 0012).
- **AI 점검 전에 코드 점검:** 겹치는 기능(확정된 같은 역할), 빈 단계, 위험 · 주의 등급, 오래된 릴리스를 코드로 보고 사실마다 출처를 단다. 수집 오류는 "확인 못 함"으로 둔다(불변 2).
- **저장 모양:** 단계 · 위치 · 연결선을 새 칸에 두고, 옛 판 칸은 지우지 않고 계산해 채운다. 옛 확정 이력과 내보내기가 그대로 열린다.

## 고민한 것
(인터뷰 기록에 버린 안 목록은 없다. 아래는 계획의 표와 컷 라인에서 DocsChecker가 정리한 것이다.)
- **격자 그대로 다듬기:** 위험이 작지만 사용자가 원한 자유 배치 · 연결 · 단계 모드가 안 된다.
- **캔버스를 직접 만들기:** 새 의존성은 없지만 끌기 · 확대 · 연결 · 미니맵을 이틀 안에 만들 수 없다.
- **@xyflow/react 13.x:** 최신이지만 나온 지 2주가 안 돼서 뺐다.
- **AI 점검을 확정 때마다 자동으로:** 비용과 호출 한도(하루 10번, 허가 F)를 넘기 쉽고, 누르지 않은 AI 결과는 쓰지 않는다는 규칙(적용 시나리오와 같음, SPEC-4.2)과 맞지 않는다.
