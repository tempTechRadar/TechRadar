# 0001. 안내서는 참고 기준으로 유연하게 적용한다

- 날짜: 2026-11-16
- 상태: 채택

## 맥락
`프로젝트3-안내서.html`은 "바깥 변화 감시 → 사건 → 알림 → 사람 승인 → 조치·기록" 서비스를 예시로 든다. 우리 팀의 메인 아이디어는 AI 코딩 기술 소식을 보안으로 거르고, 관계 지도로 보여 주고, 내 프로젝트에 적용할지 판단을 돕는 서비스다.

## 결정
안내서는 그대로 따를 의무가 없는 참고 기준이다. 팀 아이디어(`docs/문제정의.md`)를 우선하고, 안내서와 다르게 간 곳은 이 폴더에 이유를 남긴다. 제출·기록 항목은 `docs/제출물-체크리스트.md`로 놓치지 않게 관리한다.

## 결과
- 필수 8가지에 억지로 맞추지 않는다. 다만 평가에 쓰이는 기록·문서 항목은 체크리스트로 챙긴다.
