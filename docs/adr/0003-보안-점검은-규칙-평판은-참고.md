# 0003. 보안 등급은 코드 규칙으로, 커뮤니티 평판은 참고로만

- 날짜: 2026-11-16
- 상태: 채택

보안 등급(통과/주의/위험)은 라이선스, 최근 활동, 알려진 취약점(OSV·deps.dev·GitHub Advisories), 스킬·MCP 코드의 위험 패턴 같은 코드 규칙으로만 매긴다. 같은 입력에 같은 결과가 나와야 채점과 설명이 가능하기 때문이다. 커뮤니티 리뷰는 Claude API로 평판 요약을 만들어 보여 주되 자동 차단에는 쓰지 않는다. 의견은 틀릴 수 있기 때문이다. 다만 보안 사고 제보는 "주의"로 올린다. "위험" 기술도 지도에는 표시하지만 적용 후보로는 고를 수 없다.
