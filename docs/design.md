# 디자인 (알림 화면부터)

> 상태: **초안, 팀 확인 전.** 지금은 알림 목록·상세(P-7)만 정했다. 다른 화면은 이 토큰을 가져다 쓰되, 필요하면 여기를 먼저 고친다.
> 예시 화면: `docs/wireframes/alerts.html`(브라우저로 열기, 샘플 데이터). 토큰의 실제 정의: `docs/wireframes/wireframe.css`.

## 고른 것
- **스타일: shadcn** (흑백 바탕에 상태색만, 군더더기 없음). 후보였던 clean·ant는 주색의 글자 대비가 기준(4.5:1)에 못 미쳐(3.68, 4.10) 뺐다.
- **정보 밀도: 보통.** 목록 한 줄에 종류·기술 이름·상태·시각만 넣고, 자세한 것은 상세에서 보여 준다.
- **이유:** 이 서비스는 위험을 알리는 도구라 색이 상태에만 쓰일 때 위험이 눈에 띈다. 주색 검정은 흰 배경에서 21:1이다.
- 선택은 사용자(황재웅)가 했다. 2026-11-18.

## 색 (의미 네 가지: 위험·경고·성공·중립)
| 토큰 | 값 | 흰 배경 글자 대비 | 쓰는 곳 |
|---|---|---|---|
| text | #111827 | 17.7 | 본문 |
| muted | #4B5563 | 7.6 | 보조 글 |
| primary | #000000 | 21.0 | 주 버튼 |
| danger | #B91C1C | 6.5 | 보안 경고 |
| warning | #B45309 | 5.0 | 판단 대기 |
| success | #15803D | 5.0 | 완료 |
| border-strong | #6B7280 | 4.8 | 입력·버튼 테두리(UI는 3:1 이상이면 됨) |

연한 배경(danger-bg #FEF2F2, warning-bg #FFFBEB, success-bg #F0FDF4) 위의 글자도 4.8~5.9로 4.5 이상이다.

**스타일 파일의 원래 값에서 고친 것:** 성공 #16A34A(3.30)·경고 #D97706(3.19)는 흰 배경 글자로 4.5에 못 미쳐 진하게 바꿨다. 위험 #DC2626(4.83)은 통과하지만 세 색의 진하기를 맞추려고 같이 올렸다.

## 글자·간격
- 글자 크기: 12 / 14 / 16 / 20 / 24 / 32. 글꼴은 Geist(없으면 시스템 한글 글꼴). 앱에는 아직 불러오지 않았다.
- 간격: 4 / 8 / 12 / 16 / 24 / 32.

## 지키는 규칙
- 상태는 색과 **글자 라벨**을 함께 쓴다(보안 경고, 적용 기회, 판단 대기, 완료).
- 색, 간격, 글자 크기는 토큰에서만 가져온다. 화면에 내부 문서 ID(IA-6 등)를 보이지 않는다.
- 누르는 곳은 높이 44px 이상, 키보드로 모두 쓸 수 있고, 포커스 테두리가 보인다.
- "알림이 없음"과 "불러오지 못함"을 다르게 보여 준다. 판단 저장에 실패하면 "아직 판단 대기"라고 알려 준다.
- 데스크톱을 먼저 만들었고, 알림 화면은 390px 폭에서도 깨지지 않게 확인했다(IA-Q8).

## 아직 안 정했거나 사람이 확인할 것
- 보기 편함, 문구(쉬운 말인지), 다른 브라우저·기기에서 보이는 모습은 사람이 눈으로 확인한다.
- Geist 글꼴을 앱에 실제로 불러올지(Next.js 기본 제공, 설치는 미확인).
- 상태 알림 문구("판단 대기", "보류" 등)가 팀 용어와 같은지(GLOSSARY 확인 필요).
