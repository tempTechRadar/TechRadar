## I-004 · 2026-11-17 · 팀원 v5 통합과 후보 비교표
- 브랜치: `docs/problem-v5-candidates` (PR #5 위에서 시작, PR은 main 기준)
- 출처: 안내서 5장(후보 비교, 두 문서가 다르면 둘 다 적기), `docs/문제정의-차세일-v5.md`, stage-check 1단계 결과(후보 비교 🟡)

| 칸 | 내용 |
|---|---|
| 문제 | 팀원 v5가 main에 따로 있고 통합본은 v4 대기 상태로 멈춰 있다. 안내서가 요구하는 후보 비교표(6질문)가 없다 |
| 기대 결과 | 통합본의 가설 B가 v5 기준으로 바뀌고, A·B 사이 충돌(뉴스형 접음, 숫자 하나 다름, 판정 규칙 다름)이 양쪽 출처와 함께 적히고, 후보마다 6질문 표가 있음 |
| 영향 범위 | `docs/문제정의.md`, 기록 파일. `docs/문제정의-차세일-v5.md`는 고치지 않음(팀원 원본) |
| 제약 | 한쪽으로 정리하지 않는다(안내서 6장, 팀 규칙). "아직 모름"은 AI 추측으로 채우지 않고 인터뷰 질문 번호로 남긴다 |
| 열린 질문 | 방향 최종 결정은 인터뷰 후 팀이 |

**결과:** 가설 B를 v5 기준으로 바꾸고, 중단 기준과 충돌 표(5개)를 넣음. 후보 비교표 완성: C가 가장 덜 막히고, ⓑ는 사건보다 검색 기능이 맞아 보임(팀 제안). 손해(2번)·기간(6번)은 인터뷰 전이라 셋 다 아직 모름. 이어서 두 번째 수집으로 3번 "변경 전후 자료"를 A·C에서 "예"로 만듦(P13). 남은 일: 팀 토론 기록

| 칸 | 내용 |
|---|---|
| 문제 | 점검 스킬의 요건 목록을 만든 사람이 직접 뽑아 검증이 없었다. 실제로 후보 비교표·팀 토론 기록이 빠져 있었고, 작업(PR)별 점검이 없었다 |
| 기대 결과 | 요건마다 출처([안내서 n장] / [팀 규칙])가 붙고, 빠진 요건 19개·약한 요건 18개가 반영되고, PR 하나를 점검하는 "작업 점검" 방식이 생김. ➖는 구체적인 ADR로만 인정 |
| 영향 범위 | `.claude/skills/stage-check/SKILL.md`, `references/requirements.md`, 기록 파일 |

| 열린 질문 | 팀원 가이드라인의 V1–V15를 흡수할지(PR #1 합친 뒤) |

**결과:** 검토자 대조로 빠진 요건 19·약한 요건 18 반영, 요건마다 출처 표시, 작업(PR) 점검 방식 추가, ADR 0001은 ➖ 근거에서 제외. 시험 실행으로 팀 토론 기록(❌)·후보 비교(🟡)를 이제 잡아내는 것을 확인, 메모 5개 반영. 작업 중 PR #2·#3·#4가 이미 합쳐진 것을 발견해 브랜치를 최신 main으로 옮김. 남은 일: V1–V15 흡수, 팀원 v5 문제정의 통합
