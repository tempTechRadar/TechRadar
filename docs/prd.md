## 0. 한 줄 요약

AI 코딩 도구로 만드는 사람이 **내가 깐 기술의 목록·보안·더 나은 대안**을 한눈에 보고, 바깥 변화(새 취약점, 같은 역할의 새 기술)가 생기면 **알림을 받아 판단하고 기록**하며, 쌓인 목록을 **설치 프롬프트로 만들어** 컴퓨터를 바꿔도 다시 세팅할 수 있게 한다. 기준 문장: **지키고(보안), 고르고(판단), 옮긴다(설치 프롬프트).**

- 대표 사용자: 바이브코딩 부트캠프 수강생 (문제정의 4절, `docs/uj.md` 주인공)
- 주 숫자 **[D4]**: 내 기술 목록 가운데 보안 등급과 이유를 확인한 기술의 비율 (문제정의 7절, UJ-4)

| ID | 요구 | 끝 기준 | 출처 |
|---|---|---|---|
| PRD-F8 | **OSV**(취약점), **공식 MCP 레지스트리**(새 서버), **GitHub 저장소 정보**(최근 활동·라이선스, 서버 토큰으로), **npm·PyPI 다운로드 수**(사용량), **Hugging Face**(인기 모델·스페이스), **Hacker News**(인기 점수)를 **하루 1번 예약 실행**과 **"지금 한 번 실행"**으로 모아, 같은 모양(출처, 대상, 이전 값, 현재 값, 시각)으로 저장한다. 값이 바뀐 것만 수집 자료로 남기고, 실행마다 언제·어디를·몇 건·성공 여부를 남긴다. 3순위로 **Firecrawl로 skills.sh 인기 페이지 1곳**(스킬 설치 수, 스킬은 다운로드 수가 없어서). robots.txt는 공개 페이지 허용(`/api/`·`/search`만 막음, 2026-11-17 확인), 이용약관은 쓰기 전에 확인 | 배포한 앱에서 실행 기록이 간격대로 쌓임. 버튼으로 바로 한 번 돎. 같은 값을 다시 읽으면 수집 자료가 늘지 않음. **두꺼운 기술만 정기 확인**: 매일 OSV·새 버전 확인, 바뀐 게 없으면 거기서 끝(관문 셋, `docs/데이터설계.md` 8절) | 안내서 필수 2, `docs/data-sources.md`, IA-15, ADR 0008 |

### 판단과 조치

| ID | 요구 | 끝 기준 | 출처 |
|---|---|---|---|
| PRD-F17 | 알림마다 사용자가 **적용 후보** 또는 **보류**(이유 필수)로 판단한다. **보안 경고의 적용 후보는 "고친 버전으로 올리기"**이고, 고친 버전이 없으면 보류만 고를 수 있다(ADR 0012). **판단 전에는 아무것도 바뀌지 않는다.** 관리자도 남의 알림에는 판단을 대신하거나 건너뛸 수 없다(본인 알림에는 다른 사용자와 같은 규칙으로 판단할 수 있음, ADR 0016) | 판단 전에는 **판단 기록·조치가 없음**(설치 프롬프트 기본 포함, 보류 사유 없음). 적용 시나리오는 참고 자료라 판단 전에도 있을 수 있음. 관리자 화면에 남의 알림 판단 버튼 없음, API·DB로도 막힘. 보안 경고에서 고친 버전이 없으면 [보류]만 보이고, 위험한 버전은 적용 후보로 저장되지 않음 | 불변 1, UJ-5, UJ-6, UJ-M4, ADR 0010·0012·0016 |

**기능을 잘라 내지 않고 모두 순위를 붙인다.** 팀 3명이 `docs/plan.md`에서 순위별로 각자 맡을 조각을 나누고, **위 순위부터 되는 데까지** 만든다. 아래 순위는 위 순위가 시연 가능해진 뒤에 시작한다.

| 순위 | 요구 | 한 줄 |
|---|---|---|
| **1-0 얇은 한 줄** (먼저 끝낼 것) | 안내서 287–290줄 "처음에는 자료 한 곳, 사건 한 종류, 조치 한 가지로 끝까지 연결하고, 그다음에 알파": **OSV 1곳 → 보안 경고 1종류 → 판단(조치 = 판단 저장) → 기록 → 흐름 화면에 그 실행이 보임**, 시뮬레이터로 시연 | 1순위 안의 첫 이정표. 기능을 자르지 않고, 이 줄이 배포 앱에서 끝까지 돈 뒤에 1순위의 나머지를 붙인다 |
| **1 핵심 길** | F1, F3–F22, F24, F26–F30 (F8은 OSV·MCP 레지스트리·GitHub·npm·PyPI) | 등록 → 내 기술 목록 → 등급 → 보안 경고 → 판단 → 기록, 관리자·흐름 화면·시뮬레이터·채점 |

| **3 확장 여지** | 플러그인 읽기(SQ7), F32 추천, F34 쓰고 있어요, F35 사용기, F36 갤러리·내 레이더, F37 소식판, F38 모델 지원 종료, F39 다른 도구 설정 파일, F40 연동 서비스·개념, F41 보류 회고, F42 비교 모드, F43 이번 주 요약, F8의 Hugging Face·Hacker News·Firecrawl, F23의 외톨이 표시 | 사용자가 모이면 커지는 기능. 데모에서는 자리만 있어도 됨 |
