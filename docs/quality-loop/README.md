## 0. 방식

**랄프 루프:** 같은 목표 문장을 매 바퀴 다시 읽고, 지난 바퀴의 파일 · 기록을 보고 이어서 고친다. 끝 조건(아래 "완료 약속")이 참일 때만 멈춘다. 마켓의 `ralph-loop` 플러그인은 이 컴퓨터에 받아져 있지만 켜져 있지 않고, 그 명령(`/ralph-loop`)은 사람만 부를 수 있어서, 같은 방식을 세션 안에서 바퀴(라운드)로 돌린다. 바퀴는 최대 3번.

**완료 약속(이게 참일 때만 끝):** 마지막 바퀴의 감사에서 "높음" 발견 0, 고친 것마다 독립 검토가 통과, `npm test` · `tsc` · `build` 통과, 고친 파일이 모두 영역 C 목록 안.
