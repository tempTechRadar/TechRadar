무채색, 팀 확인 전. 모든 값은 tokens.css의 토큰이에요. 테마는 토큰 값만 바꿔 입혀요. 구현 세션은 이 이름(c-btn, c-chip …)과 모양을 그대로 옮겨요.

색 역할 · 상태 · 범주

글자는 늘 먹색 계열. 상태 · 범주 색은 점 · 띠 · 아이콘에만 쓰고, 기호나 글자와 함께 써요(색만으로 뜻을 전하지 않음).

단추 c-btn

높이 44px. 화면마다 진한 단추(주요 동작)는 하나. 작은 단추(32px)는 같은 줄에 큰 대안이 있을 때만. 이름은 실제로 하는 일.

모양쓰는 곳
primary화면의 주요 동작 하나(판단 저장, 상세 보기, 확정)
기본나머지 동작
눌린 상태 aria-pressed판단 단추·거르기·탭처럼 켜고 끄는 것
disabled못 쓰는 이유를 옆이나 title에 늘 함께(예: 위험한 버전은 적용 후보 불가)
quiet안내 상자 안의 보조 동작

칩 · 태그 c-chip c-tag

칩 = 누르거나 뺄 수 있는 것(내 분류 이름표, 묶음 값 고르기). 태그 = 읽기만(분야 · 종류 · #하는 일 · 판단 상태). NEW는 진한 태그 하나로만.

보안 표시 c-sec

위험 · 주의는 원 안의 기호 + 글자. 수집 오류는 점선(색이 아니라 모양). 지도의 점에서는 같은 기호를 점 옆 작은 표로, 위험은 깜박이는 고리(움직임 줄이기면 멈춤).

안내 상자 c-notice

15절 상태 규칙의 모양. 빈 상태 = 점선, 읽지 못함 · 저장 실패 = 굵은 테두리(role="alert"), 일부만 읽음 = 왼쪽 굵은 띠.

아직 판단한 기술이 없어요지도에서 관심을 남기면 여기에 모여요.
지도를 읽지 못했어요기술이 없다는 뜻이 아니에요.
기술 3개는 확인에 실패했어요점선 고리로 표시했어요.

입력 · 탭 · 알림 줄 c-field c-tabs c-toast

입력은 이름표를 늘 위에(자리 표시 글로 대신하지 않음). 탭은 아래 굵은 줄. 알림 줄은 저장 결과를 한 줄로, 3.5초 뒤 사라지고 화면 읽기 프로그램에 읽힘(role="status").
