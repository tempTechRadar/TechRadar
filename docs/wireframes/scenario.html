와이어프레임입니다. 이름과 숫자는 모두 샘플이고, 실제 데이터가 아닙니다. 알림 상세(IA-7) 안에서 판단 카드 아래에 붙는 "적용 시나리오" 카드(IA-8)의 상태 여섯 가지예요. 시나리오는 참고 자료라 판단 전후 언제든 만들 수 있고, 실제 설치·적용은 하지 않아요(ADR 0010).

① 만들기 전 (누르기 전에는 만들지 않아요)

적용 시나리오

이 알림을 어떻게 적용할지 참고용으로 정리해 줘요. 설치나 적용은 하지 않고, 판단을 돕는 글만 만들어요. 누르면 하루 5번 중 한 번을 써요(오늘 남은 횟수 4번).

② 만들었어요

적용 시나리오 참고 자료

11월 19일 14:02에 만들었어요. 판단 전후 언제든 볼 수 있어요.

적용 단계

  1. 고친 버전 0.1.16으로 올리는 것이 먼저예요. 설정 파일의 버전을 바꿔 주세요.
  2. 설치 명령은 공식 문서에서 직접 확인하세요.
  3. 바꾼 뒤 연결이 되는지 한 번 확인해요.

  • 위험: 버전을 올린 뒤 연결 설정이 달라질 수 있어요.
  • 되돌리기: 설정 파일의 버전을 이전 값으로 돌리면 돼요.

③ 안 될 때 (모두 "완료"로 보이지 않아요)

만들지 못했어요 → 다시 요청

적용 시나리오를 만들지 못했어요. 알림과 판단은 그대로예요. 잠시 뒤에 다시 요청해 주세요.

오늘 5번을 다 썼어요

오늘은 적용 시나리오를 5번 모두 만들었어요. 내일 0시(한국 시간)부터 다시 만들 수 있어요. 이미 만든 시나리오는 위에서 볼 수 있어요.

서비스 전체 한도에 닿았어요 / 연결이 안 돼 있어요

지금은 적용 시나리오를 만들 수 없어요. 잠시 뒤에 다시 시도해 주세요. (한도 때문이면 내일 0시에 풀려요)

이전 시나리오를 못 불러왔어요

시나리오를 불러오지 못했어요. 없는 게 아니에요. 잠시 뒤에 다시 불러와 주세요.

④ 알림 상세 안에서의 위치

  ├─ 비슷한 지난 판단
  ├─ 적용 시나리오   ← 새로 붙는 카드 (이 문서)
  └─ 판단 (적용 후보 / 보류)
