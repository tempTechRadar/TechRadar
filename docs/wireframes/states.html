화면 상태 모음

무채색, 팀 확인 전. 화면마다 같은 규칙으로 빈 상태 · 불러오는 중 · 읽지 못함 · 일부만 읽음 · 로그인 필요 · 저장 실패를 보여요. 문구는 샘플이에요.

"없음"과 "읽지 못함"은 다른 모양없음 = 점선 테두리 + 다음에 할 일. 읽지 못함 = 굵은 테두리 + "~이 없다는 뜻이 아니에요" + 다시 시도(불변 2).
일부만 읽음은 숨기지 않음읽은 것은 보이고, 못 읽은 것은 몇 개·어떤 것인지 왼쪽 굵은 띠로. "통과"나 "없음"으로 채우지 않음.
저장 실패면 그대로 둠판단·관심·기록 저장이 실패하면 이전 상태 그대로, "저장했어요"를 띄우지 않음, 쓴 글은 지우지 않음(불변 4).
불러오는 중은 자리만모양만 흐린 막대로. 가짜 숫자·가짜 점을 그리지 않음(불변 6). 3초가 넘으면 "아직 읽는 중" 한 줄.
문구는 무엇이 · 왜 · 어떻게사과하지 않고, 모호하지 않게. 단추는 실제로 하는 일 이름(다시 읽기, 로그인, 거르기 풀기).
