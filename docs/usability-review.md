# 전체 사용성 점검 · 고칠 곳 · 비슷한 서비스에서 빌려 올 점 (2026-11-20, 제안)

> 대상: 시안 `docs/wireframes/radar.html`(지도), `journey.html`(새 기술 · 상세 · 내 레이더 · 알림 · 기록 · 시작), `blueprint.html`, `classify.html`, `states.html`. 앱 코드는 보지 않았다.
> 방법: `docs/uj.md`의 여정을 과제로 처음 온 사람처럼 따라감(내장 브라우저, 1440px · 390px · 키보드) + 닐슨 10원칙 + 접근성 기본 + 제품 불변 규칙. 비슷한 서비스는 조사 도우미 2개가 문서·화면을 읽고, 핵심 주장 6개는 원문을 다시 열어 확인했다(5개 맞음, 1개 일부만 맞음).
> 심각도: **막힘**(과제를 못 끝냄) · **헷갈림**(끝내지만 헤맴) · **다듬기**. 크기: 작음(반나절 안) · 중간(하루) · 큼(하루 넘게). 이 문서는 고치지 않고 목록만 만든다. 고칠 것은 사용자가 고른다.

## 1. 요약

**가장 큰 문제 5개**
1. **찾기가 이름 전체를 정확히 쳐야만 된다**(U1). "postgres"·"데이터베이스"로는 아무것도 못 찾는다. 지도의 첫 과제(“데이터베이스 쪽 위험한 MCP 찾기”)가 여기서 막힌다.
2. **첫 화면에 "판단 대기"가 안 보인다**(U2). 메뉴 배지 "알림 2"뿐이다. UJ-1("판단 대기는 첫 화면에서 눈에 띄게")과 어긋난다.
3. **묶음을 누르면 접히고, 이름을 누르면 목록이 열린다**(U4). 두 동작의 차이가 보이지 않아 실수로 접힌다. "이 분류만 보기"는 마우스를 올려야 보여서 터치로는 못 쓴다.
4. **화면마다 갈래 이름이 다르다**(U19). 지도·상세는 새 10갈래인데, 새 기술·알림은 옛 4분야("코드 작성" 등)를 쓴다.
5. **근거 링크가 없다**(U14). 상세·비교표에 출처 링크와 라이선스가 없다. UJ-4·UJ-6("항목마다 출처, 없으면 찾지 못함")을 못 채운다.

**추천 다음 작업(동결 전, 작은 것부터)**: U1 찾기 → U2 판단 대기 띠 → U19 갈래 통일 → U4 누르기 동작 정리 → U14 출처 칸(시안 + 구현 넘김). 모두 시안 기준 작음~중간 크기다.

Renovate: 사람 승인 전에는 PR을 만들지 않는 설정 → 우리 원칙과 같은 방향, 묶음(groupName) · 시간표(schedule)로 알림 줄이기, 오류는 따로 보이는 칸 | **자동 PR · 자동 병합 · 자동 닫기**(불변 1과 충돌). Renovate는 승인 설정을 켜도 보안 PR은 바로 만든다(원문 확인) | Dependabot 원문 확인, Renovate 일부 확인(체크박스로 승인한다는 말은 문서에 없음) |
